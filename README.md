# MAREA

Arcipelago 3D condiviso tra amici: torni ogni giorno, la tua isola ha prodotto, costruisci, sfidi un amico a un minigioco. Browser, da link, anche dal telefono.

- Regole per chi lavora qui: `CLAUDE.md`. Design: `docs/GDD.md`. Tecnica: `docs/TECH.md`. Tappe: `docs/ROADMAP.md`.
- Comandi: `npm run dev` · `npm run build` · `npm test` · `npm run deploy`.
