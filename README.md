# MAREA

Arcipelago 3D low-poly a pixel, condiviso tra amici. Vivi a Borgo Marea, arredi la tua casa, vinci monete nei minigiochi e nelle isole a tema (Corse, Templari, Dungeon, Adrenalina, Arena, Difesa) e le spendi nelle botteghe. Si gioca nel browser, anche dal telefono, da un link.

- **Vuoi lavorarci col tuo AI?** Leggi `docs/CONTRIBUIRE.md` (preparazione, issue, PR, `/consegna`, deploy automatico).
- Regole per gli AI: `CLAUDE.md` (Codex e gli altri lo trovano da `AGENTS.md`). Dove sta il codice: `docs/MAPPA.md`. Dove va il gioco: `docs/VISIONE.md`. Com'è: `docs/GDD.md`.
- Comandi: `npm run dev` · `npm run build` · `npm test` · il deploy lo fa GitHub dopo il merge su `main`.
